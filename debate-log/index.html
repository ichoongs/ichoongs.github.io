녹음과 시간 맞추기

녹음에서 박수 시작 시각을 찾아, 아래 앱 표시 시각을 빼서 입력하세요.
녹음 시각 = 앱 경과 시간 + 보정값. 이미 기록한 발언 시각은 바뀌지 않습니다.

박수가 실제로 녹음되었는지 양쪽 파일에서 확인하세요. 표시를 보고 박수치는 반응 시간만큼 오차가 생길 수 있습니다. 두 녹음의 보정값은 각각 다르므로, 결합할 파일에 맞춰 적용하세요. 웹앱은 음성 메모의 녹음 상태를 확인하거나 제어하지 않습니다.

JSON 백업 복원

반복해서 사용하기

현재 토론을 기기 보관함에 저장하고 새 토론을 만듭니다. 다음 토론에서 주제·전체 인원·찬반 배치·좌석·태그를 다시 조정할 수 있어요.

기기 보관함도 브라우저 데이터이므로, 오래 보존할 자료는 JSON과 녹음 파일을 별도 저장하세요.
